## 数据流

```
┌──────────────┐
│  技能文件    │
│  SKILL.md    │
└──────┬───────┘
       │
       │ 加载
       ↓

│  SkillModule (dspy.Module)               │
│  - skill_text: 优化参数                   │
│  - predictor: ChainOfThought             │
└──────────────────────────────────────────┘
       │
       │ 包装
       ↓
┌──────────────────────────────────────────┐
│  评估数据集                               │
│  ├─ train.jsonl  (50%)                   │
│  ├─ val.jsonl    (25%)                   │

       │

       │
       │ 输出
       ↓

       │
```

## 优化器选择

```
开始优化
    │
    ├─→ 尝试 GEPA
    │       │
    │       ├─ 成功 → 使用 GEPA
    │       │         (反射式进化,最强大)
    │       │
    │       └─ 失败 → 降级到 MIPROv2
    │                   (贝叶斯优化,备选)
    │
    └─→ 代码进化?
            │
            ├─ Yes → Darwinian Evolver
            │         (外部 CLI,AGPL v3)
            │
            └─ No → DSPy 优化器
```
