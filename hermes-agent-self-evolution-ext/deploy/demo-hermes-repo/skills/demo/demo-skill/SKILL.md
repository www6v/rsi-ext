# Demo Skill - Testing Evolution Pipeline

## When to Use
Use this skill when you need to test the self-evolution pipeline with a simple example.

## Procedure
1. Read the user's task input carefully
2. Identify the key requirements
3. Provide a clear, concise response
4. Verify your response addresses all requirements

## Example
**Task:** Summarize the benefits of evolutionary optimization

**Response:**
Evolutionary optimization offers several key benefits:
- Automated improvement without manual intervention
- Ability to explore large solution spaces
- Adaptive to changing requirements
- No gradient information needed

## Pitfalls
- Don't overcomplicate simple tasks
- Ensure responses are actionable
- Verify constraints are met
